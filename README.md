# Award deadlines

A subscribable calendar with entry deadlines, shortlists and ceremonies of the major creative awards (Cannes Lions, D&AD, The One Show, ADC, Clio, TDC and others).

Subscribe in Apple Calendar via File → New Calendar Subscription, using the raw URL of `award-deadlines.ics`.

Dates marked with ≈ are estimated from the previous year and not yet official. Every event links to its source.

`tools/build_ics.py` builds the .ics file from the list of dates inside it: `python3 tools/build_ics.py award-deadlines.ics`
